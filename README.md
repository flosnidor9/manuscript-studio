# Write Supporter

책으로 만들 글을 웹에서 편안하게 쓰고 다듬는 정적 웹 애플리케이션입니다. 단순한 메모장이 아니라, 원고의 내용과 조판 설정을 함께 관리하여 화면에서도 실제 책에 가까운 읽기 경험을 제공합니다.

## 목표

- 글쓰기 중에는 방해를 최소화하고, 필요할 때는 책 조판 수준까지 형태를 조절한다.
- 원고와 모든 설정을 하나의 JSON 파일로 내보내고 다시 불러온다.
- 서버 계정 없이도 브라우저에 작업 내용을 안전하게 자동 저장한다.
- 정적 웹사이트로 배포하여 어디서든 브라우저만으로 사용한다.

## 핵심 기능

### 원고 편집

- 제목, 부제, 저자, 장·절, 본문, 인용문, 각주 등 책 원고에 맞는 블록 편집
- 조판된 원고 화면에서 Markdown 단축 입력(`# ` 장 제목, `## ` 소제목, `> ` 인용문)
- 실시간 글자 수, 단어 수, 문단 수, 예상 원고지 매수·페이지 수 표시
- 찾기·바꾸기, 정규식 검색, 전체 바꾸기
- 맞춤법 검사와 반복어·긴 문장·공백 오류 등 문장 점검 도구
- 이미지와 표 삽입, 캡션·대체 텍스트 관리
- 집중 모드, 다크 모드, 전체 화면, 인쇄 미리보기
- 원고지 보기: 200자·400자 원고지 등 칸 수를 선택하고, 한 글자씩 칸에 맞춰 표시
- 원고지의 줄·칸·여백 색상과 종이 질감을 조절하는 디자인 옵션

### 책 조판 설정

- 판형 선택: A4, A5, B5, 신국판, 국판, 문고판 및 사용자 정의 크기
- 용지 방향, 여백, 제본 여백, 단면/양면, 페이지 번호 위치 설정
- 본문·제목·부제·인용문·각주·머리말/꼬리말별 글꼴, 글자 크기, 굵기, 글자색, 배경색 설정
- 한글 명조·고딕·손글씨체와 영문 세리프·산세리프 글꼴을 검색·미리보기·선택
- 제목용·본문용 글꼴 조합을 테마로 적용하거나, 각 스타일을 개별 설정
- 지원 브라우저에서는 사용자의 명시적 권한을 받은 뒤 컴퓨터에 설치된 글꼴 목록을 불러와 선택
- 설치 글꼴 목록 접근을 지원하지 않는 브라우저에서는 제공 웹 글꼴·기본 글꼴과 글꼴 파일 직접 추가로 대체
- 라이선스가 허용된 사용자 글꼴 파일을 추가해 사용
- 선택한 글꼴이 PDF 및 인쇄 결과에도 유지되도록 웹 글꼴 포함과 대체 글꼴 지정
- 자간, 행간, 문단 간격, 문단 첫 줄 들여쓰기, 좌우 정렬 및 양쪽 맞춤 설정
- 장 제목·본문·인용문·각주 등 스타일을 각각 설정하고 재사용
- 고아/과부 줄 방지, 장의 새 페이지 시작, 쪽 나누기, 줄바꿈 규칙 등 인쇄용 흐름 제어
- 문단부호, 전각/반각 문자, 한글·영문·숫자 혼용에 맞춘 조판 옵션
- 완성본을 표지·판권·목차·본문으로 구성하는 책 미리보기
- 원고지, 소설책, 에세이집, 잡지 등 디자인 테마와 사용자 정의 테마
- 표지 이미지·제목·저자명 배치, 장 시작 페이지, 장식선·드롭캡 등 시각 요소 설정
- 소설·에세이·시집·리포트에 맞춘 표지 템플릿, 색상 팔레트, 제목·본문 글꼴 조합
- 페이지 수와 종이 두께를 바탕으로 한 책등 폭 계산 및 책등 미리보기
- 양장·무선제본 느낌의 표지 그림자, 종이 가장자리, 책 넘김 애니메이션을 갖춘 3D 책 보기
- 장 번호·제목·인용문·삽화를 배치하는 장 시작면(오프닝 페이지)
- 장면 전환을 위한 장식선·별표·문양 구분자와 첫 글자를 크게 꾸미는 드롭캡
- 책 제목·장 제목·저자명·쪽수를 상하단에 배치하는 머리말과 꼬리말
- 마지막 읽은 위치를 기억하고 디자인을 설정할 수 있는 가상 책갈피
- 백색지, 미색지, 재생지, 노트지, 원고지 등 종이 배경과 질감 테마
- 점선 리더·장 번호·쪽수 위치를 선택할 수 있는 목차 디자인
- 본문 여백 또는 별도 블록으로 표현하는 인용문·각주·주석 스타일
- 한 페이지씩 넘기는 책 읽기 모드와 연속 스크롤 읽기 모드 전환
- 재단선, 도련, 제본 여백, 안전 영역을 미리보기에 표시하는 인쇄 가이드

### 한국어 글쓰기 보정

- `...`를 가운데 말줄임표 `⋯`로 자동 변환하거나, 저장·내보내기 전에 일괄 변환
- 연속 공백, 잘못된 줄바꿈, 중복 문장부호 정리
- 따옴표, 대시, 괄호 등 문장부호를 책 스타일로 통일
- 변환 전 미리보기와 되돌리기 지원

### 저장과 복원

- 편집 중인 원고를 IndexedDB에 자동 저장
- 마지막 변경 시각과 저장 상태를 화면에 표시
- 브라우저를 닫았다 열어도 최근 작업 자동 복원
- 여러 원고를 로컬 라이브러리에서 생성, 이름 변경, 복제, 검색, 삭제
- 원고 내용과 조판 설정, 메타데이터를 포함한 JSON 가져오기/내보내기
- JSON 형식 검사와 버전 마이그레이션으로 이전 파일 호환
- 선택적으로 HTML, Markdown, PDF 인쇄용 문서 내보내기
- 브라우저 인쇄 대화상자를 통해 PDF로 저장하며, 선택한 판형·여백·페이지 번호·양면 구성을 반영

### 편집 히스토리

- `Ctrl/Cmd + Z`: 실행 취소
- `Ctrl/Cmd + Y` 및 `Ctrl/Cmd + Shift + Z`: 다시 실행
- 입력을 자연스러운 단위로 묶는 히스토리와 변경 전후 상태 관리
- 원고별 세션 히스토리, 저장 지점 표시, 최근 변경 목록

### 접근성·사용성

- 키보드만으로 모든 주요 편집·설정 기능 사용
- 명확한 포커스 표시, 충분한 색 대비, 스크린 리더용 레이블
- 반응형 화면: 데스크톱은 편집기와 미리보기 동시 표시, 작은 화면은 전환형 인터페이스
- 자동 저장 실패, 가져오기 오류, 지원하지 않는 브라우저에 대한 복구 안내

## 화면 구성

1. **내 서재** — 저장된 원고를 찾아 열고, 새 원고를 만든다.
2. **편집기** — 원고를 작성하고 서식을 적용한다.
3. **책 미리보기** — 선택한 판형과 조판 설정을 즉시 반영해 페이지 단위로 보여 준다. 원고지·연속 스크롤·책 넘김 보기, 디자인 테마, 인쇄 가이드를 이곳에서 전환한다.
4. **조판 설정** — 글꼴, 여백, 자간·행간·들여쓰기, 페이지 흐름을 조절한다.
5. **내보내기** — JSON 백업과 HTML·Markdown·인쇄용 PDF 출력을 제공한다.

## 구현 기준과 호환성 정책

### 원본 형식과 가져오기

- 앱 내부의 기준 원본은 블록 기반 JSON이다. 장·문단·인용문·각주·이미지와 모든 조판 설정을 구조적으로 보존한다.
- Markdown 단축 문법은 조판된 원고 화면에서 블록을 빠르게 전환하는 입력 방식이다. Markdown으로 표현할 수 없는 고급 조판 정보는 JSON에만 보존하며, 변환 시 손실될 수 있는 항목을 미리 안내한다.
- HTML·Markdown·PDF는 배포 또는 인쇄용 결과물이며, 다시 편집할 원본으로는 JSON 프로젝트 파일을 권장한다.

### 프로젝트 파일과 이미지

- 자동 저장 중에는 원고와 이미지·글꼴 같은 대용량 자산을 IndexedDB에 분리해 저장한다.
- 기본 백업은 원고, 설정, 자산을 하나로 묶은 `.write-supporter.zip` 프로젝트 파일로 내보낸다. 내부에는 `document.json`과 이미지·사용자 추가 글꼴 파일이 포함된다.
- 텍스트만 필요한 경우에는 가벼운 단일 JSON 내보내기도 제공한다. 이 경우 이미지와 추가 글꼴은 포함되지 않음을 명확히 표시한다.

### 글꼴 정책

- 설치 글꼴은 이름과 스타일 정보만 프로젝트에 저장한다. 다른 기기에서 해당 글꼴을 찾지 못하면 지정한 대체 글꼴을 사용하고, PDF 미리보기·내보내기 전에 누락 사실을 경고한다.
- 사용자가 직접 추가한 글꼴 파일은 해당 브라우저의 로컬 저장소에만 두며, 사용자가 선택한 경우에만 프로젝트 백업에 포함한다.
- 글꼴 파일을 포함하거나 배포하는 책임은 사용자에게 있으며, 앱은 글꼴 라이선스 확인 안내를 제공한다.

### 자동 저장과 복구

- 입력 후 짧은 지연 시간 안에 자동 저장하고, 저장 중·성공·실패 상태와 마지막 저장 시각을 표시한다.
- 원고마다 최근 변경 기록과 사용자가 이름 붙일 수 있는 복구 지점을 유지한다. 일괄 변환·가져오기·대규모 편집 전에는 자동 복구 지점을 생성한다.
- IndexedDB 공간 부족 또는 저장 실패 시 즉시 안내하고, JSON 또는 프로젝트 파일로 내보낼 수 있는 복구 화면을 제공한다.
- 브라우저 데이터 삭제, 시크릿 모드, 다른 기기에서는 로컬 저장 내용이 유지되지 않을 수 있으므로 정기 백업을 안내한다.

### 실행 취소와 한글 입력

- 텍스트 입력, 블록 이동·삭제, 조판 설정 변경, 이미지 삽입, 말줄임표 일괄 변환을 모두 실행 취소/다시 실행 대상으로 기록한다.
- 한글 조합 입력 중간 상태는 별도 기록으로 쪼개지 않고, 조합 완료 후 자연스러운 입력 단위로 묶는다.
- 저장 지점은 실행 취소 기록과 별개로 유지한다. 저장 후에도 이전 변경을 되돌릴 수 있다.

### PDF와 인쇄

- 첫 버전의 PDF는 브라우저 인쇄 기능으로 생성하는 ‘가정용·소규모 인쇄용 PDF’다. 사용자가 선택한 판형, 여백, 머리말·꼬리말, 쪽수, 표지와 인쇄 가이드를 반영한다.
- 재단선·도련·양면 인쇄 결과는 브라우저와 프린터에 따라 차이가 날 수 있으므로, 내보내기 전에 인쇄 미리보기와 최종 확인 목록을 제공한다.
- 인쇄소 제출용 PDF/X, 색상 프로파일, 정확한 재단·접지·책등 계산은 고급 출판 기능으로 분리한다. 지원 전에는 인쇄소 납품을 보장하지 않는다.

### 원고지와 읽기 화면

- 원고지 모드는 200자·400자·사용자 정의 칸 수, 가로쓰기·세로쓰기, 줄과 칸의 간격을 지원한다.
- 문장부호·괄호·말줄임표의 칸 배치와 쪽 나누기는 선택한 원고지 규칙에 따라 미리보기로 확인한다.
- 원고지·책 넘김·종이 질감은 읽기와 미리보기용 표현이다. 실제 인쇄 조판은 별도 책 조판 설정을 기준으로 한다.

## 기술 방향

- 프런트엔드만으로 동작하는 정적 웹페이지
- IndexedDB를 기본 저장소로 사용하고, 필요한 경우 Local Storage는 가벼운 UI 설정에만 사용
- Service Worker를 통한 앱 셸 캐싱과 오프라인 실행 지원
- 브라우저의 File API로 JSON 파일을 직접 가져오고 내보내기
- 조판 결과는 CSS의 paged-media 기능을 우선 활용하고, 브라우저별 차이는 인쇄 전용 스타일로 보완
- PDF는 인쇄 전용 CSS를 적용한 뒤 브라우저의 “PDF로 저장” 인쇄 기능을 사용한다. 별도 서버나 유료 PDF 서비스가 필요 없다.
- 로컬 글꼴 목록 접근은 HTTPS 환경에서 사용자의 동의를 받아야 하며, 브라우저 지원 여부에 따라 기능을 점진적으로 제공한다.

## 우선 구현 순서

1. **첫 버전** — 블록 기반 편집기, 기본 책 미리보기·조판 설정, 한글 입력을 고려한 실행 취소/다시 실행
2. **첫 버전** — IndexedDB 자동 저장·복구 지점·원고 라이브러리, JSON 프로젝트 가져오기·내보내기
3. **첫 버전** — 찾기·바꾸기, 가운데 말줄임표 자동 변환, 브라우저 인쇄 기반 PDF·HTML·Markdown 내보내기
4. **다음 버전** — 원고지 보기, 디자인 테마·표지·목차 편집, 사용자 글꼴과 이미지가 포함된 ZIP 프로젝트 파일
5. **고급 기능** — 3D 책 보기·책등 계산, 맞춤법·문장 점검, 전문 인쇄소용 PDF, 고급 조판

## 원칙

- 사용자 원고는 기본적으로 외부 서버로 전송하지 않는다.
- 자동 저장은 사용자가 저장을 의식하지 않아도 안전하게 동작해야 한다.
- 변환·정리 기능은 언제나 변경 내용을 확인하거나 되돌릴 수 있어야 한다.
- 책의 미학을 살리되, 쓰는 동안에는 빠르고 단순해야 한다.
